# 📝 萌娃吃播视频脚本生成指南

## 脚本框架模板

### 开场环节 (30 秒)
```
[镜头1: 主角全身镜头，做出期待表情]
旁白：「今天满满/卯卯要和大家分享什么美食呢？」

[镜头2: 特写镜头 - 食物展示]
旁白：「哇，这看起来太好吃了！」
```

### 品尝环节 (1-2 分钟)
```
[镜头3: 中景 - 坐姿吃播]
旁白：「满满/卯卯要开始品尝了，看看表情如何呢？」

[镜头4: 特写 - 表情反应]
主角做出各种表情：
- 惊喜表情（嘴巴张大，眼睛发亮）
- 享受表情（闭眼咀嚼，点头）
- 思考表情（托腮想象）
```

### 互动环节 (30 秒)
```
[镜头5: 主角转向镜头]
主角：「你们喜欢吃这个吗？在评论区告诉满满/卯卯吧！"
旁白："别忘了点赞、关注、分享哦！"
```

### 结尾环节 (10 秒)
```
[镜头6: 特写 - 满足笑容]
主角："拜拜，下次再见！"
```

## 脚本类型

### 类型 A: 新食物探险
- 开场引入新食物
- 描述食物特点
- 展示品尝过程
- 分享个人感受

### 类型 B: 美食对比
- 展示两种不同食物
- 依次品尝对比
- 表达喜好差异
- 观众投票互动

### 类型 C: 挑战类
- 特殊吃法挑战（如黑暗中吃播）
- 限时吃播挑战
- 粉丝建议吃播
- 增加娱乐性和悬念

### 类型 D: 知识性
- 食物营养介绍
- 烹饪小贴士
- 美食文化分享
- 教育性内容

## 对白技巧

### 表情描述词汇库
- **惊喜**: "哇哦！"、"天哪！"、"太棒了！"
- **享受**: "好好吃！"、"太美味了！"、"这是我的最爱！"
- **沉思**: "嗯...这是什么味道呢？"、"有点不一样呢"
- **挑战反应**: "哈哈，有点挑战呢"、"下一个！"

## 内容长度建议
- 短视频（抖音/TikTok）: 15-60 秒
- 中等视频（YouTube Shorts）: 3-5 分钟
- 完整视频（YouTube）: 8-15 分钟

## 关键要点
- ✅ 保持快节奏，避免冗长
- ✅ 强调萌娃的自然表情反应
- ✅ 定期互动，鼓励观众参与
- ✅ 展示食物的视觉吸引力
- ✅ 使用简单、有趣的语言
