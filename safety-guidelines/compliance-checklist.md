# ✅ 儿童安全和合规性检查清单

## 儿童安全标准检验

### 🛡️ 身体安全

#### 食物安全
- [ ] 所有食物来自安全、清洁的来源
- [ ] 食物新鲜，无过期
- [ ] 无易卡喉的食物（坚果、葡萄、爆米花等大颗粒）
- [ ] 无尖锐或硬的食物块
- [ ] 食物温度适宜（不过热）
- [ ] 无潜在过敏原或已通知家长
- [ ] 无过量糖分或高盐分食物
- [ ] 符合儿童营养建议

#### 环保和卫生
- [ ] 拍摄环境清洁卫生
- [ ] 使用的餐具消毒过
- [ ] 萌娃手部清洁
- [ ] 拍摄前洗手
- [ ] 食物接触表面干净

#### 环境安全
- [ ] 无锋利物品在可及范围
- [ ] 椅子和桌子稳固
- [ ] 地面防滑
- [ ] 周围无绳索或缠绕物
- [ ] 照明安全，无闪光
- [ ] 温度舒适（不过冷或过热）

#### 时间和精力
- [ ] 拍摄时长不超过 30 分钟
- [ ] 每 15-20 分钟休息 5-10 分钟
- [ ] 在孩子精力最充沛的时间拍摄
- [ ] 不在孩子疲劳或饥饿时拍摄
- [ ] 充分的休息和进食时间

### 🧠 心理安全

#### 行为和表情
- [ ] 不强迫任何不自然的行为
- [ ] 尊重孩子的情绪和反应
- [ ] 不嘲笑或贬低孩子
- [ ] 避免过度表演或夸张
- [ ] 使用积极、鼓励性语言

#### 内容敏感性
- [ ] 避免带有明显性别刻板印象的内容
- [ ] 避免涉及身体隐私的内容
- [ ] 不涉及暴力或恐怖元素
- [ ] 不涉及不当的权力动态
- [ ] 保护孩子的隐私和尊严

#### 监护人参与
- [ ] 监护人始终在场或可随时获得联系
- [ ] 监护人同意视频内容
- [ ] 监护人知道拍摄意图
- [ ] 建立安全词/信号（孩子不适时使用）

### 👶 年龄适宜性

#### 2-3 岁
- [ ] 短视频内容（最多 3-5 分钟）
- [ ] 简单、安全的食物
- [ ] 温和的互动
- [ ] 最小化风险

#### 4-6 岁
- [ ] 可增加内容长度（5-10 分钟）
- [ ] 可尝试更多食物种类
- [ ] 可加入简单互动和对话
- [ ] 仍需监护人密切关注

#### 7-12 岁
- [ ] 内容可更加复杂有趣
- [ ] 可参与更多互动和游戏
- [ ] 可表达个人想法
- [ ] 仍需维持适度监督

## 平台内容政策遵循

### YouTube 政策
- [ ] 内容标记为儿童相关内容 ("Made for Kids")
- [ ] 无不适合儿童的语言或话题
- [ ] 无广告植入违规
- [ ] 符合 YouTube 儿童频道政策
- [ ] 无数据收集违规

### 抖音/TikTok 政策
- [ ] 遵守平台年龄限制
- [ ] 无涉及不安全挑战的内容
- [ ] 无过度商业化
- [ ] 遵守社区准则
- [ ] 内容可被推荐给所有年龄用户

### B站政策
- [ ] 遵守网络文化经营许可证要求
- [ ] 符合中国儿童内容规范
- [ ] 无涉及未成年人保护的违规
- [ ] 适当的内容标签和分类

### 通用平台政策
- [ ] 无虚假或误导性声称
- [ ] 无过度的产品推广
- [ ] 无收集儿童数据的行为（无需同意）
- [ ] 无发布未授权内容
- [ ] 尊重他人知识产权

## 食品安全指南遵循

### 营养平衡
- [ ] 不将不健康食物美化为健康选择
- [ ] 避免长期高糖/高盐/高脂肪食物展示
- [ ] 提供营养信息或建议（如适用）
- [ ] 展示多样化食物
- [ ] 鼓励健康饮食习惯

### 食物准备
- [ ] 食物妥善清洁
- [ ] 储存条件适当
- [ ] 准备卫生
- [ ] 无交叉污染
- [ ] 遵守食品安全标准

### 过敏和敏感信息
- [ ] 标注常见过敏原（坚果、乳制品、贝类等）
- [ ] 获得监护人关于已知过敏的知情同意
- [ ] 避免未经充分测试的食物组合
- [ ] 提供安全的替代品信息

## 视觉和听觉内容规范

### 视觉内容
- [ ] 无过度暴露或不当姿态
- [ ] 穿着得体、年龄适宜
- [ ] 无过度的美化或修饰（尤其是脸部）
- [ ] 背景及周围环境适当
- [ ] 光线安全（无频闪或过亮）

### 听觉内容
- [ ] 无不适合儿童的语言
- [ ] 音量安全（无过度刺耳声音）
- [ ] 音乐选择适合儿童
- [ ] 无恐怖或令人不安的音效
- [ ] 对话清晰易懂

## 法律和权利保护

### 版权和知识产权
- [ ] 音乐有适当许可
- [ ] 背景无受保护内容
- [ ] 使用的任何资源均合法获得
- [ ] 原创内容或有明确引用

### 隐私和肖像权
- [ ] 获得监护人对发布内容的明确同意
- [ ] 儿童身份信息保护
- [ ] 无过度个人信息暴露
- [ ] 遵守当地儿童肖像权法律
- [ ] 建立内容撤下政策（如监护人要求）

### 商业合规
- [ ] 披露任何赞助或合作
- [ ] 无误导性的商品推广
- [ ] 符合广告标准
- [ ] 无目标儿童进行不道德营销

## 检查清单使用指南

### 每次拍摄前
1. 完成所有 🛡️ 身体安全检验
2. 完成 🧠 心理安全检验
3. 确认 👶 年龄适宜性
4. 获得 👶 年龄组的特定安全措施

### 发布前
1. 复查 🛡️ 和 🧠 部分
2. 检查平台政策遵循
3. 检查食品安全指南
4. 检查视觉和听觉规范
5. 检查法律和权利保护

### 定期审查
- 每月审查一次内容合规性
- 根据平台政策更新检查清单
- 收集观众和专业反馈
- 调整流程以进一步改进安全性

## 应急联系方式

- **儿童健康问题**: 立即停止拍摄，联系医疗专业人士
- **食品过敏反应**: 立即寻求医疗帮助
- **心理问题**: 停止拍摄，安抚孩子，必要时寻求专业帮助
- **平台违规**: 参考平台指南或联系平台支持
